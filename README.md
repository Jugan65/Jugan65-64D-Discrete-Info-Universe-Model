# 64D-DRE Replication Package

This package reproduces the results of the paper "64-Dimensional Discrete Reasoning Engine" (Nature, 2026).

## Important Notice

The core algorithm is **proprietary and patent-pending**.
Full source code is not publicly available. The compiled binary module is provided for replication purposes only.

## Installation

Copy `core_engine.cpython-*.so` to your Python site-packages or keep it in the same directory.

## Requirements

- Python 3.12
- No external dependencies (uses only standard library)

## Run Demos

```bash
python demo/demo_paper_results.py
